## Guidelines & Core Assets:
1. **Templates (`my-project/.specify/templates/`)**:
   - `tasks-template.md`: Deconstruct feature requests into user stories and atomic micro-tasks (`[ID] [P?] [Story]`).
   - `plan-template.md`: Technical architecture and execution plan.
   - `spec-template.md`: User stories, priority rankings (P1, P2, P3), and acceptance criteria.
   - `checklist-template.md`: Quality gates and validation requirements.

2. **Constitution (`my-project/.specify/memory/constitution.md`)**:
   - Follow strict engineering principles: Library-first, test-first, simplicity (YAGNI), and deterministic behavior.

3. **Execution Pattern**:
   - Structure planning around user stories and atomic phases.
   - Execute phase-by-phase without jumping ahead or making unverified assumptions.
